# Contributing

Contributions should be vendor-neutral, technically verifiable, safe by default, and suitable for production review.

## Requirements

- Never include real client names, tax identifiers, credentials, IP addresses, database contents, licence keys, or personal data.
- Use reserved examples such as office.example, 192.0.2.0/24, 198.51.100.0/24, and 203.0.113.0/24.
- Keep assessment scripts read-only.
- Document prerequisites, expected results, rollback, and limitations.
- Link to primary vendor or standards documentation where possible.
- Run the repository validation workflow before requesting review.
