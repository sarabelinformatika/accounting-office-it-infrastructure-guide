# 09 — Microsoft 365 and email security

## Identity and access

Require MFA for all users, block legacy authentication, protect emergency accounts, and use Conditional Access where licensing permits. Separate privileged administration and review risky sign-ins, consent grants, forwarding, inbox rules, and authentication-method changes.

## Mail security

- Publish SPF, DKIM, and DMARC using a staged enforcement plan.
- Apply anti-phishing, impersonation, malware, attachment, and link protections appropriate to licensing.
- Restrict automatic external forwarding.
- Display or otherwise identify external messages where it improves user awareness.
- Protect high-risk roles such as management, payroll, finance, and tenant administrators.
- Define a process for suspicious-message reporting and investigation.

## Collaboration

Control SharePoint, OneDrive, Teams, guest, and anonymous sharing. Each externally shared workspace needs an owner, business purpose, review interval, and expiry/removal process.

## Recovery

Microsoft 365 service availability and retention features do not automatically satisfy every backup and recovery requirement. Define independent recovery objectives for Exchange Online, SharePoint, OneDrive, Teams, and Entra ID configuration. Test granular restore and export procedures.

## Audit evidence

Record tenant identity, licence assumptions, administrator roles, MFA coverage, Conditional Access state, mail authentication, forwarding, guest access, retention, audit availability, backup coverage, and unresolved exceptions.
