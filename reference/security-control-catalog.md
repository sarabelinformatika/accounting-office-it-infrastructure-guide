| M365-01 | Tenant identity, mail and sharing controls are reviewed | Tenant assessment |
| BAK-01 | Versioned, off-site and protected backups cover critical data | Coverage matrix |
| BAK-02 | Recovery tests demonstrate RTO/RPO | Recovery record |
| MON-01 | Critical services, capacity, security and backups are monitored | Monitoring inventory |
| IR-01 | Incident and continuity procedures are exercised | Exercise report |
| GOV-01 | Changes, suppliers and exceptions have accountable owners | Approved records |
